PAYIN INFORMATION

WestPay supports Mobile Money payments through hosted payment pages.

Payment URL format:

https://westpay.cloud/pay

The customer enters their number and confirms the transaction through Mobile Money.

After successful payment, the customer is redirected to the merchant's return URL.

PAYOUT INFORMATION

WestPay supports automated payouts.

Merchants can transfer funds directly to supported Mobile Money wallets.

Payouts require:

- Valid merchant account
- Sufficient balance
- Supported country
- Supported operator

WEBHOOK INFORMATION

WestPay supports webhook notifications.

Webhook events notify merchants about confirmed payments.

Webhook security uses:

HMAC-SHA256 signatures.

Merchants must verify signatures before processing notifications.

AUTHENTICATION

WestPay uses:

- JWT Authentication
- API Keys

JWT tokens are required for protected endpoints.

API keys may be required for specific services.

OTP REQUIREMENT

Burkina Faso

Orange Money Burkina Faso requires an OTP code.

The customer generates an OTP before validating the payment.

PAYMENT TROUBLESHOOTING

If a merchant reports a payment issue:

Request:

- Merchant slug
- Transaction reference
- Amount
- Country
- Date and time
- Error message

Never confirm a payment without verification.

PAYOUT TROUBLESHOOTING

If a merchant reports a payout issue:

Request:

- Merchant slug
- Transaction reference
- Recipient number
- Amount
- Country
- Error message

Never guarantee payout completion times.

API TROUBLESHOOTING

Error 400

Explain:

The request may contain invalid or missing fields.

Ask the merchant to verify all required parameters.

Error 401

Explain:

Authentication failed.

Verify:

- JWT token
- API key
- Authorization header

Error 403

Explain:

Access denied.

The account may not have permission to access the requested resource.

Error 404

Explain:

Requested resource not found.

Verify endpoint URL and identifiers.

Error 409

Explain:

Conflict detected.

A transaction may already exist.

Error 429

Explain:

Rate limit exceeded.

Reduce request frequency and retry later.

Error 500

Explain:

Server-side error.

Retry later and contact support if the issue persists.
