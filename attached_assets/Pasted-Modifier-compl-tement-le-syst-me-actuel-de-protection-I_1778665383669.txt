OBJECTIF
━━━━━━━━━━━━━━━━━━━

Quand un utilisateur clique sur le lien de connexion :

- il ne doit PAS voir directement le formulaire login
- il doit d’abord passer par une page de vérification IP

Cette page doit simplement afficher :

- son adresse IP
- un message de vérification
- un bouton copier IP

Ensuite :
l’utilisateur envoie son IP à l’administrateur via Telegram/WhatsApp/support.

Puis :
l’administrateur ajoute manuellement l’IP dans le dashboard sécurité et clique :
“Donner accès”

Après validation :
→ l’utilisateur peut accéder normalement à la page login.
