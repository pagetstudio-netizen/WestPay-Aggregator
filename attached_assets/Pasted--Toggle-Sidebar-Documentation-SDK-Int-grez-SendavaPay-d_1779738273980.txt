Authentification HMAC-SHA256
Toutes les requêtes sont signées avec HMAC-SHA256 pour garantir la sécurité. Les SDK gèrent automatiquement la signature.

// Chaque requête est signée avec HMAC-SHA256
// Le SDK le fait automatiquement pour vous.
//
// Headers envoyés :
//   x-api-key: VOTRE_API_KEY
//   x-signature: HMAC-SHA256(API_SECRET, JSON.stringify(payload))
//
// Le serveur vérifie la signature avant d'exécuter la requête.
// Cela garantit que seul le détenteur du secret peut faire des appels.

Pays, opérateurs & code OTP
Liste des pays et opérateurs supportés — certains opérateurs exigent un code OTP pour valider le paiement.

📱 Code USSD — composé par le client

Le client ouvre le clavier de son téléphone et compose un code USSD (ex : *144*4*6*5000#). Orange Money traite alors la demande et envoie automatiquement un code OTP par SMS au client.

✦ Ce code est composé par le client — pas par votre application

🔐 Code OTP — saisi dans votre interface

Après avoir composé le code USSD, le client reçoit un code OTP (6 chiffres) par SMS. Votre interface affiche un champ de saisie. Le client entre ce code pour finaliser le paiement.

✦ Ce code est entré dans votre application — vous l'envoyez à l'API

Pays	Opérateur	Devise	Code USSD client ①	OTP requis ②	Flux
🇹🇬 Togo	TMoney, Moov	XOF	—	Non	USSD push auto
🇧🇯 Bénin	MTN, Moov	XOF	—	Non	USSD push auto
🇨🇲 Cameroun	MTN, Orange	XAF	—	Non	USSD push auto
🇧🇫 Burkina Faso	Orange Money	XOF	*144*4*6*[MONTANT]#	Oui ②	USSD → OTP
🇨🇮 Côte d'Ivoire	Orange Money	XOF	#144*82#	Oui ②	USSD → OTP
🇨🇮 Côte d'Ivoire	MTN, Moov, Wave	XOF	—	Non	USSD push / checkout
🇲🇱 Mali	Orange Money	XOF	#144#77#	Oui ②	USSD → OTP

Flux complet pour Orange Money (BF, CI, ML, SN)
1
Initier le paiement
Votre serveur
Appelez POST /api/sdk/payment avec le numéro et l'opérateur Orange. Réponse : { otpRequired: true, reference, ussdCode }

2
Afficher le code USSD
Votre interface
Montrez au client le code USSD à composer. Ce code est dans la réponse API sous ussdCode.

3
Composer le code USSD
Le client
Le client ouvre son clavier téléphonique et compose le code USSD. Orange Money lui envoie un SMS avec un code OTP.

4
Afficher un champ OTP
Votre interface
Affichez un champ de saisie pour que le client entre le code OTP reçu par SMS.

5
Confirmer l'OTP
Votre serveur
Envoyez POST /api/sdk/confirm-otp avec { reference, otp }. Le paiement est validé.

6
Vérifier le statut final
Votre serveur
Utilisez POST /api/sdk/verify ou attendez le webhook payment.completed.

Endpoint de confirmation OTP
// POST /api/sdk/confirm-otp
{
  "reference": "PTR_abc123",  // référence obtenue à l'étape 1
  "otp": "123456"             // code OTP saisi par le client
}

// Réponse :
{
  "success": true,
  "status": "PROCESSING",
  "reference": "PTR_abc123",
  "message": "Paiement en cours de traitement"
}

Exemple : Pour un paiement MTN au Bénin, utilisez country: "BJ" et operator: "MTN". Le numéro peut inclure l'indicatif pays (ex: +22990123456) ou être au format local (ex: 90123456).

Exemples d'int\u00e9gration
JavaScript (Node.js)
PHP
Python
1. Téléchargez le fichier SDK :

sendavapay.js
2. Utilisation :

import SendavaPay from "./sendavapay.js";

const client = new SendavaPay(
  "VOTRE_API_KEY",
  "VOTRE_API_SECRET",
  "https://sendavapay.com"
);

// 1. Collecter un paiement (USSD direct au téléphone du client)
const payment = await client.createPayment({
  amount: 5000,
  phoneNumber: "+22890123456",  // Numéro du client
  operator: "TMoney",           // MTN, Moov, Orange, TMoney, Wave...
  country: "TG",                // TG, BJ, BF, CM, CI, COD, COG
  customerName: "Jean Dupont",
  description: "Achat produit",
  callbackUrl: "https://votre-site.com/callback"
});
// { success: true, status: "PROCESSING", reference: "PTR_..." }

// 2. Attendre la confirmation (polling automatique)
const result = await client.waitForPayment(payment.reference);
if (result.status === "SUCCESS") {
  console.log("Paiement confirmé !");
}

// Ou vérifier manuellement
const status = await client.verifyPayment(payment.reference);

// 3. Retrait vers Mobile Money
const withdraw = await client.createWithdraw({
  amount: 3000,
  phoneNumber: "+22890123456",
  operator: "TMoney",
  country: "TG"
});

// 4. Solde et transactions
const balance = await client.getBalance();
const transactions = await client.getTransactions();

Format de réponse
Toutes les réponses de l'API suivent le format JSON suivant :

{
  "success": true,
  "status": "SUCCESS",
  "txid": "PTR_A1B2C3D4E5F6G7H8",
  "reference": "PTR_A1B2C3D4E5F6G7H8",
  "amount": "5000",
  "fee": "250",
  "currency": "XOF",
  "message": "Paiement validé"
}
